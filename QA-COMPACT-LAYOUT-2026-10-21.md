## Verification

Passed:

- `npm run build` — успешно; только существующее предупреждение Vite о чанках >500 KB.
- `node --test tests/*.test.mjs` — 37/37, включая регрессии положения историй, ссылок, количества фотографий и формулы ширины.
- `git diff --check` — без ошибок.
- Локальный HTTP HEAD на 127.0.0.1:4174 — 200 OK (проверка требует разрешения на сеть вне песочницы).
- Браузер: 320, 390, 620, 760, 761, 900, 1129, 1440, 1920px. У текстов карточек и подписей нет горизонтального переполнения. Карточки историй при 1129px — 496×223px. Нет фиксированной высоты текста.
- При 1129px галерея шириной 1016px: фотографии 273×205px; видимые доли кадров 1, 1, 1, 0.50003, 0. Сохранено 4:3 и object-fit:cover, без чёрных полей.
- Container queries, а не границы устройств: до 900px ширины самой галереи — 2.5 фото, до 600px — 1.25. Это сохраняет читаемые подписи; исторические 760px для двух/одной колонки историй сохранены.
- Следующее/предыдущее фото меняют горизонтальную позицию; последняя фотография Алтая достижима и загружена (naturalWidth 1600). Все пять источников сохранены.
- Вертикальная прокрутка над фото не перехватывается: scrollY изменился с 6454.5 до 7005. Нативная ArrowRight на фокусируемой галерее прокручивает ряд. Обычные подписи остаются доступны без наведения.
- В консоли локального браузера ошибок не найдено. Скриншоты в `qa/compact-layout-2026-10-21/` (игнорируются Git).

Not verified:

- Настоящий 200% browser zoom, RTL-зеркало и псевдолокализация: доступный браузер не предоставляет соответствующего безопасного переключателя. Новые направленные отступы и позиции выражены логическими CSS-свойствами, текст не зафиксирован по высоте.
