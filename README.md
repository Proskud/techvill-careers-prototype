# ТехВилл — карьерный лендинг

Интерактивный прототип карьерного лендинга IT-команды ТехВилл.

## Что внутри

- Главная: первый экран с восемью летающими 3D-фруктами команд (яблоко, манго, личи, ананас, авокадо, кокос, банан, гранат), продукты и масштаб, принцип компании, истории «Технологии с заботой» и «Технологии с умом» с фото сотрудников, блок «Работа в ТехВилле» с 3D-фруктами, бенефиты, жизнь команды с фотогалереей, «Направления и команды» и тизеры блога.
- `/vacancies` — вакансии ТехВилла и Кибершефа с поиском по названию; `/vacancies/:id` — страница вакансии с зарплатой, если она указана, и формой отклика (резюме файлом или ссылкой).
- `/blog` и `/blog/:id` — статьи с Хабра и материалы команды.
- `/ai` — AI в ТехВилле: принципы и направления.
- `/services` — решения для бизнеса, `/pentest` — информационная безопасность.
- `/privacy-policy` и `/personal-data` — политика конфиденциальности и согласия на обработку данных.
- Светлая визуальная система: графит, фиолетовый сигнал, lime-акценты, шрифт Montserrat.
- Доступность: работа с клавиатуры, видимый фокус, отключение анимаций при «уменьшить движение».
- Формы не отправляют данные: сервер для заявок и резюме ещё не подключён.

## Стек

| Слой | Технологии |
| --- | --- |
| Интерфейс | React 19, JSX без TypeScript, собственный роутинг по `window.location.pathname` (без React Router) |
| Сборка | Vite 6 с `@vitejs/plugin-react` и двумя своими Babel-плагинами: типографика (неразрывные пробелы и дефисы) в `scripts/typography-plugin.mjs` и префикс путей для GitHub Pages в `scripts/base-path-plugin.mjs` |
| Стили | Обычный CSS с переменными (`src/styles.css` и CSS-файлы страниц), без Tailwind и CSS-in-JS; шрифт Montserrat из Google Fonts |
| Анимации | GSAP, Lenis (плавная прокрутка), Motion (раскрытие карточек) |
| 3D | Three.js, React Three Fiber, Drei — фрукты в первом экране и в блоке «Работа в ТехВилле» |
| Компоненты | Radix UI Accordion (раскрытие с клавиатуры и ARIA), иконки Phosphor |
| Тесты | Встроенный тест-раннер Node.js: `node --test tests/*.test.mjs` |
| Хостинг | GitHub Pages через GitHub Actions (`.github/workflows/pages.yml`, сборка `npm run build:pages`); для хостинга на воркере есть `worker/index.js` |

## Быстрый запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

После запуска откройте `http://localhost:4173/`.

## Команды

```bash
npm run build       # production-сборка в dist/
npm run test:sites  # проверка упаковки для хостинга
node --test tests/*.test.mjs  # все тесты
```

## Структура

- `src/` — страницы, компоненты, стили и Three.js-сцены (`src/experience/`); тексты и данные — в `src/data/`.
- `public/assets/` — фотографии, иконки и логотипы, которые использует сайт.
- `scripts/` — Babel-плагины сборки и подготовка сборок для GitHub Pages и воркера.
- `tests/` — тесты на `node --test`.
- `AGENTS.md` — принятые решения по дизайну и контенту с датами; более поздние записи переопределяют ранние.
